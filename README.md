
# Примитивная база данных

Программа для создания таблиц и работы с записями. Данные сохраняются в формате JSON.

## Установка и запуск

Для установки зависимостей используется `uv`.

Установка:

```bash
uv sync
```

Запуск программы:

```bash
uv run database
```

## Управление таблицами

Поддерживаемые типы данных: `int`, `str`, `bool`.

### Команды

- `create_table <имя_таблицы> <столбец1:тип> ...` - создать таблицу.
- `list_tables` - показать список таблиц.
- `drop_table <имя_таблицы>` - удалить таблицу.
- `help` - показать справку.
- `exit` - выйти из программы.

### Пример использования

```text
create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

list_tables
- users

drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: y
Таблица "users" успешно удалена.
```

## CRUD-операции

Добавление, просмотр, изменение и удаление записей.

### Команды

- `insert into <таблица> values (<значения>)` - добавить запись.
- `select from <таблица>` - показать все записи.
- `select from <таблица> where <столбец> = <значение>` - выбрать записи по условию.
- `update <таблица> set <столбец> = <значение> where <условие>` - изменить записи.
- `delete from <таблица> where <столбец> = <значение>` - удалить записи.
- `info <таблица>` - показать структуру таблицы и количество записей.

ID генерируется автоматически. Строковые значения указываются в двойных кавычках.

## Декораторы и кэширование

Для обработки ошибок, подтверждения удаления и измерения времени выполнения используются декораторы:

- `handle_db_errors` - обработка исключений при работе с базой данных.
- `confirm_action` - подтверждение удаления таблиц и записей.
- `log_time` - измерение времени выполнения операций `insert` и `select`.

Для повторных запросов `select` используется кэширование с помощью замыкания `create_cacher()`.

После добавления, изменения или удаления данных кэш сбрасывается.
